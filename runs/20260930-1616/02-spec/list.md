# 일반고 목록

## 목적
학부모가 선택한 지역의 일반고 목록과 학교별 기본정보(주소·설립·남녀공학·학생/교원수)를 한눈에 확인하고, 비교하고 싶은 학교를 고르도록 돕는다.

## 주요 요소
- filter-chip — 상단 필터(지역·설립유형 등), 기본은 canvas-soft 채움, 선택 시 ink 채움
- school-card — 학교 카드 리스트(1단). 학교명(heading-3), 주소(body-sm, text-muted), 학생수·교원수(body-sm, tabular-nums). 비교용으로 선택하면 canvas-soft 채움 + 오른쪽 위 체크 표시
- school-tag — 카드 하단에 설립·남녀공학·중점학교(Could) 태그를 가로 나열, 순위·등수 표현 없이 속성만 표기
- data-source-bar — "기준 2026.04.01 · 출처 학교알리미" 형식으로 목록 데이터 블록 바로 아래 배치 (V2 필수)
- empty-state — 필터 결과가 없을 때 안내 문구 2줄 + button-pill-soft로 필터 초기화 유도
- button-primary — 학교를 2곳 이상 선택했을 때 하단에 "비교하기"로 학교 비교 화면 이동
