# 학교 비교

## 목적
학부모가 관심 있는 일반고 2~4곳을 실데이터로 나란히 비교해, 순위가 아닌 항목별 구간·태그 차이를 보고 판단하도록 돕는다.

## 주요 요소
- filter-chip (선택 상태) — 상단에 선택한 학교 2~4곳을 칩으로 나열, X로 제거 가능 (빈 슬롯은 "+ 선택하기"로 bottom-sheet 호출)
- bottom-sheet — 비교 대상 학교를 고르거나 바꿀 때 여는 하단 시트
- compare-bar — 항목(학생수, 교원 1인당 학생수 등)별 선택 학교 막대. 기본 막대는 chart-strong, 강조 학교 1곳만 chart-highlight, 값은 막대 끝에 직접 표기
- compare-table — 좌측 라벨 고정 + 우측 학교별 값 표, 강조 열은 canvas-soft 채움 + 인셋 링, 순위·등수 표기 없이 값만 나열
- school-tag — 학교별 구간·속성 태그(예: "학생수 중간 구간", "공립") — 서열 표현 금지
- data-source-bar — "기준 2026.04.01 · 출처 학교알리미" 형식으로 비교 데이터 블록 바로 아래 배치 (V2 필수)
- empty-state — 선택한 학교가 2곳 미만일 때 "비교할 학교를 2곳 이상 골라주세요" 안내 + button-pill-soft로 선택 화면 유도
- button-outline — 비교 대상 다시 고르기
- button-primary — 목록으로 돌아가기 / 비교 결과 저장 등 화면의 주요 행동

## 연결 유저스토리
- 3. 학부모가 관심학교 2~4곳을 실데이터로 비교한다
