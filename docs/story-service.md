# 고교나침반 — 서비스 맥락 (story-service.md)

> 출처: 고교나침반 PRD. PRD에 없는 내용은 넣지 않는다.

## 1. 한 줄 정의
고교나침반은 학교알리미·NEIS·교육청 전형포털에 흩어진 일반고 정보를 한곳에 모아, 우리 지역 일반고를 실데이터로 비교하고 선택하도록 돕는 웹 서비스다.

## 2. 주요 사용자
은평구에 사는 중3 자녀의 학부모. 특목고·자사고 대신 일반고 진학을 고려하는 가정.

## 3. 유저스토리 (5개)
1. 학부모가 시군구를 선택해 관할 교육지원청과 배정방식을 확인한다
2. 학부모가 지역 일반고 목록과 학교별 기본정보를 확인한다
3. 학부모가 관심학교 2~4곳을 실데이터로 비교한다
4. 학부모가 우선순위 조건을 선택해 추천순위를 받는다
5. 학부모가 올해 바뀐 입시정책이 우리 지역 배정에 미치는 영향을 확인한다

※ 학생 성향 입력 추천은 PRD상 2단계라 이번 범위에서 제외

## 4. 만들 화면 (5개)
| 화면 | 보여줄 것 | 우선순위 | 유저스토리 |
|---|---|---|---|
| 지역 선택 | 시군구 선택 → 관할 교육지원청, 배정방식 요약 | Must | 1 |
| 일반고 목록 | 학교 카드(주소·설립·남녀공학·학생/교원수), 중점학교 태그 | Must (중점학교 태그는 Could) | 2 |
| 학교 비교 | 선택한 2~4개교 막대 비교 + 데이터 표 | Must | 3 |
| 조건 매칭 | 우선순위 조건 → 추천순위 | Should | 4 |
| 정책 업데이트 | 입시정책 변경 타임라인 + 지역 배정 영향 | Should | 5 |

## 5. 안 할 것
- 학생 실명·성적 등 개인정보 수집
- 학교 후기 (1차 범위 제외)
- 부동산 학군·배정 아파트 정보, 특목고·자사고 진학률 랭킹

## 6. 판정 기준 — 어기면 안 되는 것
> 작업 흐름(story-work.md)의 재료가 아니다. 게이트(R5)에서 판정에만 쓴다.

| ID | 규칙 | 스크립트 판정 |
|---|---|---|
| V1 | 서열화 금지 | 화면 텍스트에 "N위" "N등" "상위 N%" "랭킹" 0건 · 학업성취도 원자료 값 0건 |
| V2 | 기준 시점·출처 표기 | 데이터가 나오는 화면마다 "기준 YYYY.MM.DD" 1개 이상 + "출처" 1개 이상 |

## 참고: 중점학업방식 데이터 메모
전국 통합 데이터셋이 없다. NEIS "학교학과정보" API는 특성화고 학과 구분용이라 부적합하고, 학교알리미 "교육과정 편성" 공시는 PDF 서술형이다. 시도교육청 개별 PDF·보도자료로만 공개되므로(예: 인천 18개교, 경기 64개교) 지역별 수작업 큐레이션이 필요하다.
