# 고교나침반 하네스 — 검증과 리뷰 (harness-verify.md)

> 기준 문서: docs/harness-gates.md (판정 규칙), docs/harness-purpose.md (완료 기준)

## 1. 판정 스크립트 검증 (tests/) [추가]

| 샘플 | 내용 | 통과 조건 |
|---|---|---|
| tests/fail-sample.html | 규칙을 일부러 어긴 시안 (목록 밖 색, "1위" 문구, 기준 시점 누락 등) | 심어둔 위반 규칙 수 = 스크립트가 잡은 규칙 수 · V1·V2는 반드시 잡힘 |
| tests/pass-sample.html | 규칙을 모두 지킨 시안 | 위반 0건 |

- 심어둔 위반 목록은 tests/expected.json에 적어두고 스크립트 결과와 비교한다
- 판정 스크립트나 rules.json을 고칠 때마다 이 검증을 다시 돌린다

## 2. 첫 실제 실행 (시험 운행)
- 화면: 학교 비교(compare), 일반고 목록(list) — PRD Must 우선순위
- 확인: docs/harness-purpose.md 4절 완료 기준 통과 여부
