# 고교나침반 디자인 시스템 (school-design.md)

> 고교나침반 서비스 전용 디자인 기준이다. 이 서비스 작업에서는 default-design.md보다 이 파일이 우선한다.
> 출처 표시: **[원본]** 전달받은 design.md · **[PRD]** school-story-service.md · **[작업]** school-story-work.md · **[스타일]** 뚜앵 디자인 스타일 규칙 · **[추가]** Claude가 고교나침반에 맞게 임의로 채운 값(확정 전)

## 01 개요

고교나침반은 학교알리미·NEIS·교육청 전형포털에 흩어진 일반고 정보를 한곳에 모아, 중3 학부모가 우리 지역 일반고를 실데이터로 비교하고 선택하도록 돕는 모바일 웹 서비스다 [PRD].

인터페이스는 **정보가 주인공이고 화면은 비켜선다**. 흰 캔버스 위 근흑색 잉크의 모노크롬 시스템이며, 구조는 그림자나 색이 아니라 옅은 중성 톤 단계와 1px 헤어라인으로 만든다 [원본]. 학교 데이터·비교 수치·태그가 화면에서 읽혀야 할 유일한 정보이고, 크롬은 그것을 액자처럼 받친다 [원본 개념 + 고교나침반 적용 추가].

색 대신 **형태가 브랜드를 만든다**. 모든 인터랙티브 요소는 알약형(`rounded.full`), 컨테이너는 24px, 입력·작은 타일은 16px 라운드 [원본]. 서체는 Pretendard 하나로, Bold 700 제목과 Regular 400 본문, Light 300 리드 문장의 굵기 대비로 위계를 낸다 [원본].

유일하게 끼어드는 색은 **일렉트릭 블루(#0066FF)** 한 가지다. 고교나침반에는 결제가 없으므로, 원본의 "상업 신호" 역할을 **"사용자가 고른 것·비교의 핵심"** 표시로 옮긴다 — 비교 차트의 강조 학교 1곳, 추천 결과 1순위 표시 [추가].

**핵심 특징**
- 흰 캔버스 + 잉크(#141414) 모노크롬, 크로마는 액센트 블루 1개뿐 [원본]
- 알약형 인터랙션: 버튼·필터칩·세그먼트·배지 모두 `rounded.full` [원본]
- 그림자 없는 깊이: 톤 단계(`canvas-soft`, `field`, `hairline`)와 1px 헤어라인 [원본]
- Pretendard 굵기 대비: 700 제목 / 400 본문 / 300 리드 [원본]
- 학교 간 차이는 순위가 아닌 **구간·태그**로 표기 [PRD]
- 모든 데이터 화면에 **기준 시점·출처** 표기 [PRD]

## 04 레이아웃

### 간격 [원본]
- 기본 단위 8px, 4px 반단계
- 토큰: `spacing.xxs` 4 · `xs` 8 · `sm` 12 · `md` 16 · `lg` 24 · `xl` 32 · `section` 48 · `section-lg` 64
- 화면 좌우 여백 16px(`spacing.md`), 섹션 간격 48px, 카드 내부 여백 24px
- 버튼 좌우 패딩 16px, 입력 패딩 12px 16px

### 화면 크기 [원본 + 작업]
| 이름 | 크기 | 비고 |
|---|---|---|
| 기준 프레임 | 390 × 844 | 모든 키스크린 기본 프레임 (피그마) |
| 최소 | 360px 폭 | 가로 스크롤 없이 유지, 긴 텍스트는 줄바꿈 |
| 태블릿·데스크톱 | — | MVP 범위 밖 |

- 기본 1단 레이아웃. 학교 카드 목록도 1단 [추가]
- 학교 비교는 **최대 4개교**. 390 폭에서는 가로 표 대신 **항목별 세로 막대 비교**로 보여준다 [PRD 수치 + 레이아웃 추가]

### 터치 영역 [원본]
- 알약 버튼·필터칩은 44px 이상 높이
- 세그먼트 옵션은 알약 전체가 터치 영역

### 여백 원칙 [원본]
- 섹션 구분은 구분선이 아니라 48~64px 여백으로
- 카드 안쪽은 24px로 헤어라인에서 내용을 띄운다

## 07 컴포넌트

### 원본에서 그대로 가져온 것 [원본]
- **`button-primary`**: `primary` 채움, `on-primary` 라벨(`typography.link`), `rounded.full`. 화면의 주요 행동 1개 ("비교하기", "추천 받기")
- **`button-outline`**: 흰 채움, `ink` 라벨, 1px `hairline` 테두리, `rounded.full`. 두 행동이 나란할 때의 보조 행동
- **`button-pill-soft`**: `canvas-soft` 채움, 테두리 없음. 외부 링크("학교알리미 ↗")·보조 이동
- **`text-input`**: `field` 채움, 테두리 없음, `text-faint` 플레이스홀더, `rounded.sm`, 패딩 12 16
- **`text-input-focused`**: 2px `ink` 링
- **`segmented-control`**: `canvas-soft` 트랙 + 흰 알약 활성 옵션, 비활성 라벨 `text-muted`
- **`badge-overlay`**: 반투명 회색 알약 `rgba(115,115,115,0.56)` + 흰 `typography.label`. 이미지 위 태그용
- **`faq-row`**: `canvas-soft` 바, `rounded.sm`, 오른쪽 셰브론. 행 간격 12px
- **`compare-table`**: 행 구분 1px 가로선, 강조 열은 `canvas-soft` 채움 + 인셋 링, 세로선 없음

### 고교나침반을 위해 채운 것 [추가]
화면 5개(지역 선택 / 일반고 목록 / 학교 비교 / 조건 매칭 / 정책 업데이트) [PRD]에 필요한데 원본에 없는 컴포넌트다.

**`region-selector`** — 지역 선택
- 시군구 목록을 `filter-chip` 여러 개로 배치(한 줄 가로 스크롤 금지, 줄바꿈)
- 선택 후 아래에 `info-summary-card`로 관할 교육지원청·배정방식 요약

**`school-card`** — 일반고 목록 카드
- 흰 채움 + 1px `hairline-soft`, `rounded.md`, 내부 여백 24
- 학교명 `heading-3`, 주소 `body-sm` `text-muted`
- 하단에 `school-tag` 가로 나열(설립·남녀공학·중점학교)
- 학생수·교원수는 `body-sm`, 숫자는 tabular-nums
- 선택 상태: `canvas-soft` 채움 + 오른쪽 위 체크 표시(잉크 원형)

**`school-tag`** — 학교 속성·구간 태그
- `rounded.full`, `typography.label`, 1px `hairline` 테두리 + 흰 채움
- 예: "공립", "남녀공학", "과학중점", "학생수 중간 구간"
- **순위·등수 표현 금지** — "1위", "상위 10%" 같은 문구를 쓰지 않는다 [PRD]

**`filter-chip`** — 조건 매칭 필터
- 기본: `canvas-soft` 채움, `ink` 라벨
- 선택: `ink` 채움, `on-primary` 라벨
- `rounded.full`, 높이 44 이상

**`compare-bar`** — 학교 비교 막대
- 항목(학생수, 교원 1인당 학생수 등)별로 선택 학교 2~4곳의 가로 막대
- 기본 막대 `chart-strong`, 강조 학교 1곳만 `chart-highlight`
- 값은 막대 끝에 직접 표기(`body-sm`)

**`match-result-row`** — 추천 결과
- 추천 순서는 목록 순서로만 표현하고 숫자 순위 배지는 달지 않는다 [PRD 해석]
- 첫 행만 왼쪽에 4px `accent` 세로 표시
- 조건 경로와 성향 입력 경로가 같은 결과 화면을 공유 [PRD]

**`policy-timeline-item`** — 정책 업데이트
- 날짜(`caption`, `text-muted`) + 제목(`title`) + 요약(`body-sm`)
- `rounded.sm` 흰 카드, 항목 간격 12
- "우리 지역 영향" 문단은 `canvas-soft` 박스로 구분

**`data-source-bar`** — 기준 시점·출처 표기 (모든 데이터 화면 필수)
- `canvas-soft` 채움, `rounded.sm`, 패딩 8 12
- `caption` `text-muted`: "기준 2026.04.01 · 출처 학교알리미"
- 비교·목록·추천 화면의 데이터 블록 바로 아래 배치

**`info-summary-card`** — 요약 카드
- `canvas-soft` 채움, 테두리 없음, `rounded.md`, 내부 여백 24

**`empty-state`** — 빈 화면
- 일러스트 대신 `text-muted` 문구 2줄 + `button-pill-soft` 1개
- 예: "비교할 학교를 2곳 이상 골라주세요"

**`bottom-sheet`** — 비교 학교 선택 등
