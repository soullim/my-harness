# 고교나침반 하네스 — 목적 (harness-purpose.md)

> 기준 문서: docs/story-service.md (무엇을 위한 서비스인지), docs/story-work.md (실제 작업 흐름)

## 1. 매번 달라지는 입력
- 이번에 만들 화면 2~3개
  - 선택지 5개: 지역 선택 / 일반고 목록 / 학교 비교 / 조건 매칭 / 정책 업데이트
  - 2개 미만 또는 4개 이상이면 실행하지 않는다
- 레퍼런스 검색어: 입력받지 않고, 고른 화면 이름에서 자동으로 만든다

## 2. 사용자
- 실행하는 사람: 나 혼자 (개인 프로젝트)
- 실행 방법: Claude Code에서 자연어로 요청
- 결과 받는 곳: 하네스 루트 폴더 안의 파일

## 3. 결과물 형태
- 시안: 390×844 HTML 파일 (화면 1개 = 파일 1개)
- 스크립트로 판정한 뒤, 통과한 시안만 피그마로 옮긴다 (피그마 전송은 선택 단계)

## 4. 완료 기준 (한 문장)
선택한 화면 수만큼 390×844 시안이 있고, 판정 스크립트의 위반 건수가 0이며(V1·V2 포함), 시안별 공유 URL 목록 파일이 있으면 완료.

| 확인 항목 | 스크립트 판정 |
|---|---|
| 시안 개수 | 시안 HTML 수 = 선택한 화면 수 (2~3) |
| 시안 크기 | 각 시안의 기준 프레임 = 390×844 |
| 위반 건수 | 판정 스크립트 결과 위반 0건 |
| V1 서열화 금지 | 순위 표현·학업성취도 원자료 0건 |
| V2 기준 시점·출처 | 데이터 화면마다 "기준 YYYY.MM.DD" 1개 이상 + "출처" 1개 이상 |
| 공유 URL 목록 | 목록 파일 존재 + 줄 수 = 시안 수 |
