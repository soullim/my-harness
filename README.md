# 고교 선택 도우미 — 데이터 연동 프로토타입

중2~3 학생/학부모가 지역 일반고를 성향별로 비교하도록 돕는 서비스의
1단계 프로토타입. 두 부분으로 구성된다.

## 1. 화면 프로토타입 (`ui_prototype.html`) — 서울 은평구 실데이터

브라우저에서 파일을 열기만 하면 동작하는 정적 HTML/JS 프로토타입.
**서울특별시 은평구 소재 일반고 9곳의 실데이터**를 담고 있다.

- 기본정보(설립·남녀공학·주소·개교일)는 NEIS 교육정보 개방포털 Open API
  (`open.neis.go.kr/hub/schoolInfo`)로 직접 조회했다. 이 API는 인증키 없이도
  호출은 되지만 **응답이 5행으로 제한**되어(트라이얼 제한으로 추정) 전체 목록을
  받으려면 결국 무료 인증키가 필요하다. 학교명을 하나씩 지정해 조회하면
  5행 제한 안에서 원하는 학교의 전체 필드를 받을 수 있어, 이번엔 그 방식으로
  은평구 소재 학교 이름을 먼저 확보(위키백과 분류 페이지로 후보를 뽑고 NEIS로
  주소를 대조해 은평구가 맞는지, 일반고가 맞는지 검증)한 뒤 학교명 단위로 조회했다.
- 학생수·교원수는 학교알리미(schoolinfo.go.kr) 학교별 공시페이지에서 가져왔다.
  이 페이지는 학급수도 공시하지만, 표 구조가 복잡해 자동 추출 과정에서
  숫자가 뒤섞이는 오류가 반복 확인되어(예: 학급수가 학생수보다 커지는 등
  명백히 잘못된 값) 이번 버전에는 **넣지 않았다**. 학생수·교원수는 서로 다른
  두 차례 조회에서 합계가 내부적으로 일관되게 나와 신뢰도가 더 높다고 판단했다.
- 위 두 출처 모두 **자동화된 파이프라인이 아니라 사람이 직접 조회하고 검증한 값**이다.
  학교알리미 수치는 매년 4월 1일 기준으로 갱신되므로 조회 시점에 따라 소폭 달라질 수 있다.

포함된 화면:
1. 은평구 일반고 9곳 카드 목록 (실제 기본정보 + 학교 홈페이지 링크)
2. 최대 4개교 비교 — 학생수·학생 1인당 교원수 막대 비교 + 데이터 표
3. 3가지 조건(규모/남녀공학/교원 배치 밀도)으로 9개교 재정렬
4. 교육정책 업데이트 타임라인 (2025~2026년 실제 동향)

**아직 없는 항목** (모두 학교알리미 공시항목에는 있으나 이번엔 안정적으로 못 채운 것):
학급수·학급당 학생수, 진로·진학 현황(4년제 대학 진학률, 특목고 진학 비율),
학업중단·전출입 현황, 선택과목 개설 수(고교학점제 관련), 학교회계 예산.
전부 표 구조가 복잡한 상세 공시 페이지에 있어, 사람이 웹페이지를 읽어 옮기는
방식으로는 오류 위험이 크다 — 아래 CSV 파이프라인으로 받아야 안전하다.

## 2. 데이터 수집 스크립트 (자동 API 연동)

- `fetch_neis.py` — NEIS 교육정보 개방포털의 학교기본정보 Open API를 실제로
  호출하는 스크립트. 인증키 없이도 호출은 되지만 5행으로 응답이 제한되므로,
  전체 지역 목록이 필요하면 무료 인증키를 발급받아 쓰는 걸 권장한다.
  ```bash
  pip install requests
  export NEIS_API_KEY=발급받은키   # PowerShell: $env:NEIS_API_KEY='발급받은키'
  python fetch_neis.py 서울특별시
  ```
  NEIS는 시도 단위(`LCTN_SC_NM`)까지만 필터링을 지원해 구 단위(은평구 등)는
  주소 문자열(`ORG_RDNMA`)에 구 이름이 포함되는지로 클라이언트에서 걸러야 한다.
- `build_profiles.py` — NEIS 기본정보와 학교알리미 공시자료(CSV)를 병합해
  5축 성향 지표를 계산하는 스크립트. 학교알리미는 공식 Open API 계약이
  문서마다 조금씩 달라, 자동 호출 대신 data.go.kr에서 CSV를 내려받아
  `disclosure_raw/merged.csv`에 두는 방식을 기본으로 했다 (스크립트 상단 주석 참고).
  CSV가 없으면 `sample_data/sample_schools.json`(가상의 예시 지역)을 그대로
  출력해 항상 결과를 볼 수 있게 했다 — `ui_prototype.html`이 쓰는 은평구
  실데이터와는 별개의, 화면 UX만 검증하던 1차 버전 더미 데이터다.

## 실제 서비스로 확장할 때 남은 일

1. `disclosure_raw/merged.csv`를 만드는 파이프라인 — 지금은 수작업 다운로드 전제.
   data.go.kr의 학교알리미 데이터셋별 정확한 공시 스키마를 확정해야 함.
2. 학급수·진로진학·전출입·선택과목·재정 지표는 CSV 병합으로만 안전하게 채울 것 —
   웹페이지를 사람이나 LLM이 읽어 옮기는 방식은 표가 복잡한 페이지에서 오류가
   났다 (이번에 실제로 겪음: 학급수 수치가 명백히 잘못 추출됨).
3. 시도교육청별 고입전형포털(배정방식·전형일정)은 API가 없어 별도 큐레이션 필요.
   `region.assignment_method` 필드가 그 자리.
4. 정책 리포트는 교육부·시도교육청 공지 RSS를 편집자가 요약하는 반자동 큐레이션으로 시작.
5. 다른 구/지역으로 확장할 때도 이번과 같은 검증 절차(NEIS로 존재·분류 확인 →
   학교알리미로 학생·교원 수 대조)를 거치는 게 안전하다.
